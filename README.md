# Netflix Data Analysis using SQL

## 📊 Project Overview
This project focuses on analyzing Netflix dataset using SQL to extract meaningful insights about content trends, genres, and release patterns.

## 🛠️ Tools Used
- SQL (MySQL Workbench)

## 📂 Dataset Details
The dataset contains information about Netflix shows and movies including:
- Title
- Type (Movie/TV Show)
- Genre
- Release Year
- Country
- Duration

## 🔍 Key Analysis Performed
- Count of Movies vs TV Shows
- Most common genres on Netflix
- Content distribution by country
- Year-wise content release trend
- Longest duration movies
- Filtering based on type and genre

## 🧠 SQL Concepts Used
- SELECT, WHERE
- GROUP BY, ORDER BY
- COUNT(), MAX()
- JOIN (if applicable)

## 📈 Key Insights
- Movies are more than TV Shows on Netflix
- Certain genres dominate the platform
- Significant growth in content after 2015
- USA has the highest content contribution

## 📌 Conclusion
This project demonstrates how SQL can be used to analyze large datasets and generate business insights for decision-making.
